# USB Workspace Dashboard V2

Automatically discovers useful content on a USB drive or selected workspace.

Features:
- Automatic removable USB detection on Windows
- Safe local-folder fallback
- Automatic discovery of documents, books, applications, Python, Linux, data and archives
- Project discovery for Git/Python/Node/Docker projects
- Click a category card to see discovered items
- Double-click a result to open it
- Search across discovered content
- Storage usage
- Portable dashboard.json configuration
- Offline operation

Run:
```powershell
python -m pip install -r requirements.txt
python usb_workspace_dashboard.py
```
